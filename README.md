# 🌦️ WeatherApp

A **React Native Weather Application** built as part of a technical assessment.  
The app provides real-time weather information, 5-day forecasts, geolocation support, sorting options, and a responsive UI that adapts seamlessly across devices and orientations.

---

## ✨ Features

- ✅ **Fetch Current Location** – automatically detects and displays weather for the user’s current city.  
- ✅ **5-Day Weather Forecast** – displays upcoming weather using **OpenWeatherMap API**.  
- ✅ **Filter & Sort** – sort forecast results by **temperature, date, or weather condition**.  
- ✅ **Portrait & Landscape Support** – responsive layout for both orientations.  
- ✅ **FlatList Implementation** – smooth, performant rendering of forecast data.  
- ✅ **Async Operations Handling** – proper loading states and error handling.  
- ✅ **Error Handling** – graceful fallback for denied permissions or API issues.  
- ✅ **State Management** – implemented with **React Hooks & Context API**.
